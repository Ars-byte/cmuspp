**CMUS++** — это музыкальный плеер для терминала, написанный на C++17. Сверхлёгкий, молниеносно быстрый, полностью управляемый с клавиатуры и без графических зависимостей.

**Возможности:**
*   **Форматы:** MP3, FLAC, WAV, OGG, OPUS, AIFF.
*   **Обложки:** Извлечение встроенных обложек из MP3, FLAC, OGG/OPUS + запасной вариант cover.jpg/png.
*   **Тексты песен:** синхронизированные `.lrc` + тексты, встроенные в теги (USLT/LYRICS), 100% офлайн.
*   **Кроссплатформенность:** Linux (ALSA), macOS (CoreAudio), Windows (WinMM).
*   **Настройка:** 86 встроенных тем + поддержка пользовательских XML-тем.
*   **Быстрый:** Нулевое время загрузки, эффективное декодирование и рендеринг без мерцания.
*   **Окно «О программе»:** Нажмите `a`, чтобы просмотреть информацию о проекте, лицензию и авторов.

## Установка и сборка

### 1. Установка зависимостей

Вам понадобится компилятор C++ и библиотеки `libsndfile`, `libjpeg` и `libpng` (а также ALSA в Linux).

*   **Ubuntu / Debian:** `sudo apt install g++ libsndfile1-dev libasound2-dev libjpeg-dev libpng-dev`
*   **Arch Linux:** `sudo pacman -S gcc libsndfile alsa-lib libjpeg-turbo libpng`
*   **macOS:** `brew install libsndfile jpeg libpng` (требуется Homebrew)

### 2. Сборка

Клонируйте репозиторий и используйте встроенный скрипт автоматической сборки:

```bash
# Дать права на выполнение
chmod +x bootstrap.sh

# Собрать
./bootstrap.sh

# Запустить!
./cmuspp
```

## Обложки альбомов

CMUS++ автоматически извлекает и отображает обложки альбомов:

*   **MP3:** Фрейм APIC (ID3v2.2/2.3/2.4)
*   **FLAC:** METADATA_BLOCK_PICTURE
*   **OGG / OPUS:** METADATA_BLOCK_PICTURE в комментариях Vorbis
*   **Запасной вариант:** `cover.jpg`, `cover.png`, `folder.jpg` и т.д. в том же каталоге

**Совместимые терминалы:**
*   **Kitty / WezTerm / ghostty / iTerm2:** Нативное отображение изображений (протокол Kitty)
*   **Другие терминалы (Alacritty, GNOME и т.д.):** Рендеринг ANSI half-block (▄) с true-color

## Тексты песен

Нажмите `l` в плеере, чтобы просмотреть текст песни во весь экран (список скрывается). 100% офлайн — без сети и внешних сервисов. Текст определяется так:

1. **Синхронизированный `.lrc`** рядом с песней (напр. `песня.mp3` → `песня.lrc`). Текущая строка выделяется и движется синхронно с воспроизведением.
2. **Текст, встроенный в теги** самого файла (фрейм `USLT` в MP3, поле `LYRICS` в FLAC/OGG). Отображается статическим текстом, прокрутка через `↑`/`↓`.

Формат `.lrc`:

```
[ti:Название]
[ar:Исполнитель]
[00:12.50]Первая строка
[00:24.00]Вторая строка
```

Поддерживает таймстампы `[mm:ss]` / `[mm:ss.xx]`, несколько таймстампов на строку (`[00:12][00:24]текст`) и тег `[offset:±ms]`.

## Управление

CMUS++ спроектирован для полного управления без мыши.

| Клавиша | Действие |
| :--- | :--- |
| `↑` / `↓` (или `k`/`j`) | Навигация по списку |
| `Enter` | Воспроизвести / Войти в папку |
| `Пробел` | Пауза / Продолжить |
| `←` / `→` (или `h`) | Назад 5с / Вперёд 5с (В браузере: на уровень выше) |
| `n` / `p` | Следующий / Предыдущий трек |
| `+` / `-` | Громкость + / - |
| `s` | Вкл/выкл Shuffle (Случайный) |
| `r` | Вкл/выкл Repeat (Повтор) |
| `l` | Показать/скрыть текст (.lrc или встроенный) во весь экран |
| `/` | Найти трек в текущей папке (введите для фильтрации, `Enter` воспроизводит) |
| `t` | Сменить цветовую тему |
| `o` | Открыть файловый менеджер |
| `a` | Показать информацию (О программе) |
| `q` | Выход |

## Пользовательские темы

Нажмите `t` внутри приложения, чтобы сменить тему. Вы можете создавать свои темы, создавая файлы `.xml` в папке `themes/` (рядом с исполняемым файлом) или в `~/.config/cmuspp/themes/`.

**Пример структуры (`themes/моя-тема.xml`):**
```xml
<?xml version="1.0" encoding="UTF-8"?>
<theme name="Моя Тема">
  <!-- Цвета текста (Светлый -> Тёмный) -->
  <fg0 r="248" g="248" b="242"/> <fg1 r="215" g="210" b="195"/>
  <fg2 r="117" g="113" b="94"/>  <fg3 r="75"  g="71"  b="60"/>
  
  <!-- Акценты -->
  <acc  r="166" g="226" b="46"/> <warn r="230" g="219" b="116"/>
  
  <!-- Фоны (bgr/bgg/bgb = фон | fgr/fgg/fgb = текст) -->
  <bghdr  bgr="39" bgg="40" bgb="34" fgr="102" fgg="217" fgb="239"/>
  <bgsel  bgr="73" bgg="72" bgb="62" fgr="248" fgg="248" fgb="242"/>
  <bgplay bgr="30" bgg="44" bgb="18" fgr="166" fgg="226" fgb="46"/>
  <bgstat bgr="29" bgg="29" bgb="24" fgr="117" fgg="113" fgb="94"/>
</theme>
```
*Новые темы будут обнаружены автоматически при перезапуске приложения.*
